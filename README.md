# Bookstore Inventory and Analytics System

## Project Overview

The Bookstore Inventory and Analytics System is a Python-based application designed to manage bookstore inventory, record sales, analyze revenue, and visualize business performance.

## Objectives

- Manage bookstore inventory.
- Add, update, and remove books.
- Track book sales and stock quantities.
- Calculate total revenue using NumPy.
- Handle CSV datasets using Pandas.
- Generate analytical charts using Matplotlib and Seaborn.

## Features

1. Inventory Management
2. Bookstore Class using OOP
3. Sales Management
4. Revenue Analysis using NumPy
5. Data Cleaning using Pandas
6. Data Visualization

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- CSV

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python bookstore_system.py
```

## Visualizations

The project generates four visualizations:

1. Bar Chart - Total Books Sold by Genre.
2. Line Graph - Monthly Sales Revenue Trend.
3. Pie Chart - Revenue Share by Book Genre.
4. Heatmap - Book Price and Sales Correlation.

All charts are saved inside the charts folder.
